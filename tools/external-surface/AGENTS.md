# External web inventory

Read root AGENTS.md and this directory's README. Keep this explicit workflow outside build/test.
Native CLIs own discovery and crawling. Passive candidates must never grant network scope.
Preserve exact origin approval, the GET-only crawler gateway, bounded execution, private
evidence and distinct responding, unmeasured and incomplete states. Verify with the offline
contract tests and native loopback acceptance.

TCP inventory has a separate scope of literal IP addresses and explicit ports. Keep
Nmap in unprivileged connect mode with discovery, DNS and scripts disabled. Only
publish states supported by validated XML. Run externalNetworkTest and native
externalNetworkAcceptance after changes.
